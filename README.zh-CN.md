# Presenter 使用说明

English: [README.md](README.md)。Presenter 的界面只有英文；本说明里的按钮名称用界面上的英文原文。

Presenter 是一个桌面放映工具。它把课件全屏放在投影屏上，在笔记本屏幕上显示控制台。

## 下载

最新的压缩包在 **[Releases 页面](https://github.com/vizenxx/presenter/releases/latest)** 的 **Assets** 里：Windows 用 `…-win.zip`，Mac 用 `…-mac.zip`。任何人都能打开这个页面：把链接发给其他老师即可。

## 打开（不需要安装）

Presenter 是一个解压即用的文件夹。没有安装程序，也不需要管理员密码。

**Windows**

1. 右键点 `Presenter-0.1.0-win.zip` → **全部解压缩**。文件夹可以放在任何地方，例如“文档”。
2. 在文件夹里双击 **Presenter**（带 Presenter 图标的那个文件）。大约 2 秒打开。
3. 想要桌面图标：右键点 **Presenter** → **显示更多选项 → 发送到 → 桌面快捷方式**。
4. 程序还没有签名。压缩包从网上下载时，Windows 可能显示“Windows 已保护你的电脑”：点 **更多信息 → 仍要运行**，只需要一次。
- 在这台电脑上，桌面图标也可以启动源码版（`Start Presenter.bat`）。

**Mac**（macOS 13 Ventura 或更新版本，Intel 或 Apple 芯片都可以）

1. 双击 `Presenter-0.1.0-mac.zip`，得到 **Presenter**。双击它打开（放进“应用程序”不是必须的）。
2. 第一次打开时，macOS 可能提示无法检查这个 App。打开 **系统设置 → 隐私与安全性**，向下滚动，点 **仍要打开**。App 用 Apple 开发者证书签名之前，需要做这一步，只做一次。
3. PPT 和 PPTX 通过 **Keynote**（每台 Mac 都有，免费）转换。第一次会提示“Presenter 想要控制 Keynote”，点 **好**。转换时 Keynote 会打开一个窗口，转换完自动关闭。没有 Keynote 时，也可以用 LibreOffice。
4. Mac 快捷键：**⌘ Return** 或 **fn F5** 开始投影；**⌘ +**、**⌘ −**、**⌘ 0** 调字号；**⌘ Z** 撤销标注；**delete** 清空标注。
5. 控制台每秒复制几次投影画面。想要实时视频画面，请在 **系统设置 → 隐私与安全性 → 录屏与系统录音** 里允许 Presenter，然后重新打开 Presenter。

## 放一份课件

1. 把课件文件拖进控制台窗口，或者点 **Open deck**。支持 PPT、PPTX、PDF 和 HTML。课件先显示在控制台里，学生还看不到。
2. 点右上角的 **▶ Start projecting**，或者按 **F5**。课件全屏显示到投影屏上。
3. 点 **■ Stop projecting**，或者按 **Esc**。投影屏关闭，课件回到控制台。
4. 投影仪必须设为“扩展”模式。没有接投影仪时，投影会以一个普通窗口显示，适合在家练习。

### 别人做的 HTML 课件

- 用 **Reveal.js**、**remark**、**impress.js** 或 **Marp** 做的课件会自动接入：页数、目录、备注和精确跳页都能用。
- 每页一个 `.slide` 元素、当前页带 `active` 标记的普通网页课件也会自动接入：页数、标题、讲者备注（例如 `data-speaker-script`、`.notes`）和计划时长都能读到。
- 其他 HTML 课件用“Key mode”：方向键翻页，程序不知道总页数。
- **Slides** 和 **Notes** 显示的是当前选中屏幕的课件。另一块屏幕放另一份课件时，选中它就能看到它自己的目录和备注。
- 想让新课件完整兼容：按 [docs/protocol.md](docs/protocol.md) 做，或者从 [examples/minimal-deck.html](examples/minimal-deck.html) 改；用 AI 做课件时，把 [docs/ai-integration.md](docs/ai-integration.md) 里方框中的英文整段贴在你的要求后面。
- 程序里的 **📘 Guide**（顶部工具栏，或首页的链接）分两部分：**1 · Use Presenter**（“我想…… → 这样做”）和 **2 · Prepare decks**（哪些课件不用准备、一键复制给 AI 的要求、保存示例课件或协议说明）。

### PPT 和 PDF 课件

- 程序先把 PPT 转成放映格式。第一次打开一份 PPT 需要十几秒，控制台顶部会显示进度。之后再打开同一份 PPT 会直接显示。
- 转换用电脑上的 PowerPoint；没有 PowerPoint 时用 LibreOffice。两者都没有时，请先把 PPT 另存为 PDF。
- 现在每页只显示最终画面：“点一下出现一条”的动画和视频暂时不会播放。保留动画的放映方式正在开发。
- 隐藏的幻灯片不会显示，和 PowerPoint 放映时一样。
- PPT 里的标题会出现在“Slides”里，讲者备注会出现在“Notes”里。
- PPT 和 PDF 按整页显示，所以字号按钮对它们不可用。

## 控制台上有什么

| 区域 | 作用 |
|---|---|
| 当前页 / 投影屏 | 没有投影时，这里直接显示课件；投影时，这里实时显示学生看到的画面 |
| 下一页预览 | 显示选中屏幕的下一页，作提醒用。点一下它，可以单独往后翻看 |
| 计时器 | 倒计时。学生在投影屏上能看到时间 |
| 目录 / 备注 | 点一下展开。点目录里的某一页，投影屏跳到那一页 |
| 底部的“Screens”栏 | 每个屏幕一张小卡片：联动、单独翻页、⋯ 菜单。最后是 **＋ Add screen** |

## 翻页

- 翻页笔、方向键、PageUp / PageDown、空格键都可以翻页。
- Home 键回到第一页，End 键跳到最后一页。

### 翻页规则

- **你选中的屏幕一定翻页。**
- 选中的屏幕勾选了 **Linked** 时，所有勾选了联动的屏幕一起翻页。
- 选中的屏幕没有勾选联动时，只有它自己翻页。

选中屏幕的方法：点一下那个画面，或者点底部的屏幕卡片。选中的卡片有橙色边框。卡片上的绿点表示学生现在能看到这个屏幕。

卡片上的 **−** 和 **+** 只移动这一个屏幕。用它们可以调整两个屏幕之间差几页。

**Next slide** 显示选中屏幕的下一页。点一下预览就选中它：翻页键只翻预览，学生看到的画面不变，可以用来往后翻看。点当前页或屏幕卡片就回到原来的屏幕，预览也回到“下一页”。预览不参与联动，底部没有它的卡片。

## 在课件上标注

当前页上方有一排工具：**鼠标、画笔、荧光笔、框选、红点、橡皮擦**，6 种颜色，以及 **Undo** 和 **Clear**。

- 在控制台的课件画面上画，或者直接在投影屏上画，两边会同时显示同样的笔迹。
- 投影时，鼠标在投影屏上移动，左下角会出现一个小工具条，几秒后自动隐藏。
- 标注是临时的：投影屏翻到别的页时自动清除。
- 控制台快捷键：**P** 画笔、**H** 荧光笔、**R** 框选、**L** 红点、**E** 橡皮擦、**Ctrl+Z**（Mac：⌘Z）撤销、**Delete** 清空。
- 按一次 **Esc** 回到鼠标，再按一次 **Esc** 停止投影。
- 投影时，“学生看到的画面”是投影窗口的实时视频，不再有延迟。

## 计时器

- 点 **1 分**、**5 分** 等按钮，计时器立即开始。
- 课件为某一页设定了计划时长时，计时器会显示“本页计划 X 分钟”。
- 时间到后铃声一直响。按任意键或点击任意处停止铃声。停止铃声的这次按键不会翻页。
- UXD202 课件用课件底部自带的计时器显示时间。其他课件在投影屏右下角显示计时器。
- **My timer**（控制台右下角）只给你自己看：选 **Count up**（正计时）或 **Count down**（倒计时），用来把握讲课节奏。学生看不到，也不会响铃。倒计时过了零点会继续走，显示 **Over time**。

## 随机点名

点顶部工具栏的 **🎲 Name picker**，右侧打开点名面板。

1. 选择名单。第一次打开时只有一份示例名单：点 **Edit**，换成你的名单（每行一个人，前面的编号可以不写）。
2. 点 **🎲 Pick a name**。投影屏和你添加的屏幕上会临时盖上一层点名画面：名单依次高亮滚动，逐渐变慢，最后停在选中的人身上。
3. 高亮停下后，按任意键或点一下画面，点名画面收起，课件回来。这一下不会翻页。高亮还在滚动时，按键无效。

规则和原来的 Lucky Roller 一样：

- 没点到过的人，被点到的机会相同。
- 勾选“People already picked can be picked again (small chance)”时，点到过的人仍可能再被点到，但概率很低。取消勾选后，点到过的人不再被点到。
- 名单上绿色标记表示点到 1 次，金色标记表示点到多次。

**重置点名记录**：按钮下方显示“已点到 X / Y 人”。点旁边的 **↺ Reset**，确认后，这份名单里所有人都变回“没点到”。点名记录只在程序打开期间保留。

管理名单：点 **New** 或 **Edit**，每行一个人，格式是“编号 姓名”。没有编号时，每行只写姓名也可以。名单会保存下来，下次打开程序还在。

没有投影时，只有控制台上显示点名结果，学生看不到。

## 添加屏幕

点底部“Screens”栏最后的 **＋ Add screen**：

- **同一份课件**：在新窗口里打开同一份课件。
- **另一份课件**：在新窗口里打开另一份课件。

- **A window on this computer**：把一个程序窗口（浏览器、视频播放器、表格……）加进来。列表里也有最小化的窗口（和 Zoom 一样）。真窗口留在你的笔记本上，你照常操作它；投影显示它的实时画面。

底部每张卡片是一份**内容**（课件或窗口），它自己记住翻到第几页。新加的内容先**待用**，不会弹出新窗口。

**放到哪块投影**：点卡片上的 **Projector ▾** 按钮，选 **Projector 1**（主投影）、另一块投影、**New projector**（第二块投影或电视；有空闲显示器时全屏打开，没有就开成普通窗口），或 **Not shown**。每块投影一次放一份内容；原来的内容回到待用，进度保留，换回来接着放。同一个菜单里有 Projector 2、3……的全屏和关闭。

**只点卡片是“选中”**：翻页键、Next slide 和 Notes 跟着它，观众看到的画面不变，可以用来悄悄翻看待用的课件。

**窗口内容**：加进来或点它的卡片，都不会动你屏幕上的窗口；在 **Projector ▾** 里给它选一块投影时，窗口才来到最前面（最小化的会还原）。翻页、标注、备注对它不适用；点 **✕** 移除。（Mac 上请自己把窗口点到最前面；第一次需要允许“录屏”。）课件卡片的 **⋯** 菜单里有字号和 **Remove**。

**浮动工具条**（Windows）：投影上的程序窗口在最前面时，屏幕上方会浮出一条置顶的小工具条，里面有标注工具和随机点名；My timer 开始计时后，也会在这里显示时间（在控制台设置和操作）。选画笔后直接在真窗口上画，笔迹同步显示在投影的画面上，直到你点清空（或这个窗口离开投影）才消失；选回鼠标就照常操作窗口。点 **◂** 收起，拖 **⠿** 移动。观众看不到这条工具条。切回控制台或别的程序时，它自动隐藏。

## “Key mode”是什么

有些课件没有接入同步协议。程序用方向键控制这种课件翻页。这时程序不知道总页数：卡片上只显示当前页码，当前页下方显示“Key mode”。翻页和计时器照常可以用。

UXD202 的课件已经接入同步协议。程序能读到总页数、每页标题、目录、每页计划时长。

## 给维护者

- 源码：`src/`。设计文档：`docs/specs/`。实施计划：`docs/superpowers/plans/`。
- 常用命令：`npm run build`（构建）、`npm test`（单元测试）、`npm run e2e`（端到端测试；接着第二块屏幕时，它隐藏运行、静音，并跳过投影步骤）、`npm run dev`（开发模式；PPT/PDF 查看页需要先 build）。
- `npm run check:start`：隐藏、静音地启动程序（接着投影仪也安全），先逐个启动，再 8 个同时启动，检查控制台都拿到了状态。每次启动都会在程序数据文件夹（Windows：`%APPDATA%\presenter`；Mac：`~/Library/Application Support/Presenter`）写 `startup-log.txt`：如果控制台一直停在 “Starting…”，这个文件会显示停在哪一步。
- 不开窗口的离屏检查：`npm run check:viewer`（PPT/PDF）、`npm run check:ink`（标注）、`npm run check:frameworks`（Reveal.js、remark、impress.js、Marp、协议示例）、`npm run check:console`（控制台排版，中英文）。
- 真实转换测试：`PRESENTER_CONVERT_IT=libreoffice npm test`（或 `powerpoint`；Mac 上用 `keynote`）。
- 压缩包：`npm run dist:win`（Windows）、`npm run dist:mac`（只能在 Mac 上运行）。没有 Mac 时，在 GitHub 上运行 **Build app zips** 工作流（`.github/workflows/build.yml`），它同时生成两个压缩包。图标源文件：`build/icon.svg`。
- 修改源码后必须运行 `npm run build`，否则桌面图标仍然打开旧版本。
